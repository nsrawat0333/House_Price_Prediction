About the Project

Project Overview

This project uses machine learning to predict house prices in California based on features like location, median income, and housing characteristics.

We've implemented several models including Linear Regression, Decision Tree, and Random Forest, with Random Forest providing the best performance.

Dataset Information

The California Housing dataset contains information from the 1990 California census, including:

Geographical location
Housing age & characteristics
Population statistics
Income levels
